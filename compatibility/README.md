# Compatibility evidence

This tree owns the pinned command/capability manifest, differential scenarios,
explicit normalizers, schemas, and generated reports. A normalizer must name
exact volatile fields and may not erase unknown output, errors, or state
differences.

## Pinned command inventory

`upstream-v1.2.1-command-inventory.json.gz` is the canonical M02 command and flag
inventory. Its runtime authority is the constructed Cobra tree from the exact
upstream commit. Its source authority is a Go AST census over production
first-party packages reachable from `cmd/bd`. The census creates review
obligations; it does not infer callback behavior.

`command-inventory-policy.json` records the admitted Linux/AMD64 CGO and
non-CGO profiles, normal and transient-completion activations, source closure,
semantic boundary, reviewed shared rules, and exclusion authority. Runtime
records never use `BD_NAME` for stable IDs.

Run `npm run inventory:commands` to regenerate the artifact. Run
`npm run test:inventory` to compare independently generated bytes with the
committed file. Both commands use the digest-pinned Go container. Runtime
observation is offline and fails if HOME, XDG, the temporary directory, or the
empty working directory changes.

The artifact is deterministic gzip JSON with an empty name, a zero timestamp,
and a fixed operating-system marker. Compression keeps the complete inventory
under the repository large-file limit without adding a pre-commit exception.
Inspect it with:

```bash
gzip -dc compatibility/upstream-v1.2.1-command-inventory.json.gz | jq .
```
