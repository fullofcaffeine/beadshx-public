# Generated Go

Generated Go is compiler-owned build material inside the existing Beadshx Go
module. Git ignores the generated Go tree. Never edit generated Go to fix a
problem. Change the owning Haxe source or the compiler instead.

Existing-module generation also owns the digest-listed license notices under
the repository-root `LICENSES/` directory. The ownership manifest in
`generated/go/bdhx` is the authority for those files.

The repository commits only the small hash fixture in
`engdocs/beadshx/generated/bootstrap-fixture.json`. The fixture records the
generated bytes, owning Haxe inputs, and exact haxe.go revision. Run
`npm run test:generated` to compare a clean generation with this fixture.
