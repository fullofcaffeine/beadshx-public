# Release engineering

Release work owns packaging, notices, SBOMs, provenance, checksums,
signatures/attestations, platform admission, installation, rollback, and
recovery evidence. A successful cross-build does not admit a platform.

`identity-policy.json` defines the names and metadata that distinguish BeadsHX
from its pinned upstream compatibility target. See
`engdocs/beadshx/operations/release-identity.md` for the readable policy.
